# 独立 Chat Agent 需求

本目录记录 AI-Nexus 将对话能力拆分为独立 Chat Agent 的业务需求。

这里不预先指定编程语言、通信协议、数据库、中间件或部署方式。后续开发应先理解需求和
当前代码，再单独完成技术调研、方案设计与协议确认。

## 当前状态

AI-Nexus 已经具备基础对话能力，但这些能力仍运行在主系统内部。独立 Chat Agent 尚未开始开发。

## 一句话目标

将对话、模型调用和后续 Agent 能力从 AI-Nexus 中独立出来，同时保持现有用户使用方式和
核心功能稳定。
